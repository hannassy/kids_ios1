# Флаги факультетов

Картинки баннеров для финального экрана теста:

| Файл | Факультет |
|------|-----------|
| `flag-gryffindor.png` | Гриффиндор |
| `flag-hufflepuff.png` | Пуффендуй |
| `flag-ravenclaw.png` | Когтевран |
| `flag-slytherin.png` | Слизерин |

Подключение в коде: `houseTheme.js` → `require("./assets/houses/flag-….png")`.

Чтобы заменить картинку: положите новый PNG с тем же именем файла и перезапустите `npx expo start -c`.

Рекомендуемый размер: портрет ~1080×1920 px (или больше), чтобы на iPhone 14 Pro Max флаг был чётким.
