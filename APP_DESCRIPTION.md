# Распределяющая шляпа — описание проекта

## О проекте (для всей семьи)

Это **семейный учебный проект**: приложение про Хогвартс и сортировку по факультетам, которое мы делаем **вместе** — папа-разработчик и дочери (13 и, возможно, 10 лет).

| Участник | Роль |
|----------|------|
| Папа | Magento-разработчик, ~12 лет опыта в вебе. Мобильные приложения — **новая область**: сначала разбирается сам, потом объясняет по шагам. |
| Старшая дочь (13) | Основной соавтор; проявляет энтузиазм — ей можно давать задачи посложнее. |
| Младшая (10) | Подключим позже, когда базовые шаги уже понятны старшей. |

### Как мы учимся

1. **Папа** сначала читает и пробует код (Expo, React Native, навигация).
2. Потом **короткий урок** дочери: что за файл, зачем библиотека, что изменить.
3. **Дочь делает сама** маленькую правку (текст кнопки, новый вопрос, цвет) — папа проверяет.
4. Каждый файл в репозитории **сильно прокомментирован**: подключения библиотек, константы, логика — чтобы можно было открыть любой `.js` и читать как учебник.

## Идея приложения

Приложение стилизовано под мир Гарри Поттера и имитирует распределение по факультетам Хогвартса. Пользователь проходит короткий тест из 5 случайных вопросов; по ответам начисляются баллы факультетам, побеждает тот, у кого сумма больше.

## Сценарий пользователя

1. Открыть приложение → экран **«Хогвартс»** (Home).
2. Через меню или кнопку перейти в **«Сортировочная шляпа»** (Quiz).
3. Нажать **«Пройти тест»**.
4. Ответить на **5** вопросов (каждый раз случайный набор из 12+ в банке).
5. Увидеть факультет и описание; **«Пройти заново»** сбрасывает тест.
6. В разделе **«Факультеты»** — прочитать про все четыре дома.

## Структура данных

- В `questions.js` — не менее **10** вопросов (сейчас 12).
- У каждого вопроса **4** варианта ответа.
- У каждого варианта объект `scores` — сколько баллов даёт каждому факультету.

### Пример вопроса

```js
{
  id: 1,
  text: "Какая черта характера тебе ближе?",
  options: [
    {
      id: "a",
      text: "Храбрость",
      scores: { gryffindor: 2, hufflepuff: 0, ravenclaw: 0, slytherin: 0 },
    },
    // ... ещё варианты b, c, d
  ],
}
```

Ключи факультетов на английском (так принято в коде): `gryffindor`, `hufflepuff`, `ravenclaw`, `slytherin`.

## Логика теста

- Константа `QUESTIONS_PER_TEST = 5` в `QuizScreen.js` — легко поменять на 7 или 3.
- При старте: перемешать все вопросы, взять первые 5.
- После каждого ответа — следующий вопрос или подсчёт результата.
- Подсчёт: сложить все `scores` выбранных ответов, выбрать факультет с максимумом.

## Идеи для следующих уроков с дочерью

- Добавить свой вопрос в `questions.js` (скопировать блок и поменять текст).
- Поменять цвет кнопки в `styles` (поле `backgroundColor`).
- Вынести Quiz на три файла: подключить `WelcomeScreen`, `QuestionScreen`, `ResultScreen` из корня.
- Добавить картинку факультета (Expo: `Image` и файл в папке `assets`).
