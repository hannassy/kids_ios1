# Концепция приложения "Рас­пределяющая шляпа"

## Идея
Приложение стилизовано под мир Гарри Поттера и имитирует процесс распределения по факультетам Хогвартса. Пользователь запускает приложение, видит приветствие и кнопку “Пройти тест”. После этого стартует серия вопросов, после которых на основе ответов предлагается наиболее подходящий факультет.

## Сценарий пользователя
1. Пользователь открывает приложение.
2. Видит приветствие и кнопку `Пройти тест`.
3. Нажимает кнопку и начинается тест.
4. На экране появляется первый случайный вопрос из набора, а также 4 варианта ответа.
5. Пользователь выбирает ответ.
6. После выбора автоматически показывается следующий вопрос.
7. Всего задается 5 вопросов.
8. После последнего вопроса показывается результат — факультет, который лучше всего подходит пользователю.
9. На экране результата есть кнопка `Пройти заново` для повторного теста.

## Структура данных
- Хранилище вопросов должно содержать не менее 10 вопросов.
- Для каждого вопроса должно быть минимум 4 варианта ответа.
- Вопросы должны быть предзаполнены и доступны в виде массива/объекта внутри приложения или внешнего JSON-файла.
- Данные пользователя (выбранные ответы) сохраняются во внутреннем состоянии до конца теста.

### Пример структуры вопроса
```js
{
  id: 1,
  text: "Какая черта характера тебе ближе?",
  options: [
    { id: "a", text: "Храбрость" },
    { id: "b", text: "Ум" },
    { id: "c", text: "Лояльность" },
    { id: "d", text: "Амбициозность" }
  ]
}
```

## Логика теста
- Количество вопросов в тесте: `5`.
- Это значение должно быть вынесено в отдельную константу, чтобы его было легко изменить.
- При старте теста выбираются 5 случайных вопросов из общего набора (10+).
- После каждого ответа сохраняется выбор пользователя.
- В конце анализируются выбранные варианты и определяется факультет.

### Пример константы
```js
const QUESTIONS_PER_TEST = 5;
```

## Вычисление результата
- Для каждого варианта ответа можно привязать баллы к факультетам.
- По итогам всех 5 ответов суммируются очки и выбирается факультет с наибольшей суммой.
- Варианты факультетов:
  - Гриффиндор
  - Пуффендуй
  - Когтевран
  - Слизерин

## Экран результата
- Отображается название факультета.
- Можно добавить краткое описание выбранного факультета.
- Кнопка `Пройти заново` сбрасывает состояние и возвращает на стартовый экран.

## Рекомендации для реализации
- Использовать экраны/компоненты:
  - `WelcomeScreen` — стартовый экран с приветом и кнопкой.
  - `QuestionScreen` — отображение вопроса и вариантов ответов.
  - `ResultScreen` — итоговый экран с результатом и кнопкой повтора.
- Хранить состояние текущего вопроса и выбранных ответов в React-состоянии.
- Для адаптивной верстки использовать относительные размеры и `useWindowDimensions()`.
- Вопросы можно хранить в отдельном файле, например `questions.js` или `questions.json`.

## Название приложения
Рабочее название: **"Распределяющая шляпа"**.
