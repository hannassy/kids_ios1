# Разработка на Windows: среда и запуск (в т.ч. iPhone через Expo Go)

Этот проект на **Expo** — не нужны Xcode на Windows и сборка «нативного» iOS-проекта на ПК.  
На **Windows** приложение на **iPhone** запускают так: компьютер отдаёт код по сети, на телефоне стоит **Expo Go** и открывает проект по QR-коду.

> **Важно про iOS на Windows**  
> Симулятор iPhone (как в Xcode на Mac) на Windows **не работает** — его нет.  
> Варианты для iOS:
> - **Реальный iPhone + Expo Go** (рекомендуется, у вас так и настроено) ✅  
> - Mac с Xcode (если появится) — симулятор или сборка в App Store  
> - Облачная сборка Expo (EAS Build) — отдельная тема, для учебного проекта не обязательна  

На том же Windows можно дополнительно: **браузер** (`w`) и **Android-телефон / эмулятор** (`a`).

---

## Устройства в семье — имеет ли значение?

**Кратко: для нашего проекта модель iPhone почти не важна; важнее свежая iOS и одинаково обновлённый Expo Go на обоих телефонах.**

| У кого | Модель | iOS (известно) | Для разработки |
|--------|--------|----------------|----------------|
| Папа | iPhone 14 Pro Max | **18.7.2** | Отлично подходит |
| Дочь | iPhone 13 | уточнить позже | Ожидаемо тоже ок (13-й поддерживает актуальные iOS) |

### Модель (14 Pro Max vs 13)

- **Expo Go и наш код** работают на обоих одинаково: один QR-код, одно приложение.
- Отличия только в **размере экрана** и «чёлке» (Dynamic Island у 14 Pro Max vs вырез у 13).  
  В проекте уже есть `useWindowDimensions()` и библиотека `react-native-safe-area-context` — интерфейс подстраивается под разные экраны.
- Имеет смысл **иногда проверять на обоих телефонах**: кнопки не обрезаны, текст читается (особенно после правок дочери).

### Версия iOS

- Проект на **Expo SDK 54** (`app.json` → `sdkVersion: "54.0.0"`).  
  Приложение **Expo Go** из App Store должно быть **последней версии** — оно подтягивает поддержку новых SDK.
- **iOS 18.7.2** у папы — нормально, конфликтов с Expo 54 не ожидается.
- У дочери на iPhone 13 посмотреть версию: **Настройки → Основные → Об этом устройстве → Версия ПО**.  
  Если iOS **15 или новее** (обычно на 13-м стоит 16–18) — для Expo Go всё в порядке.  
  Если вдруг очень старая iOS и Expo Go не ставится / пишет «обновите систему» — обновить iOS через Настройки → Основные → Обновление ПО.

### Практический совет

1. На **обоих** iPhone установить/обновить **Expo Go** из App Store в один день.
2. Оба сканируют **один и тот же** QR после `npx expo start` (каждый со своего телефона — так и задумано).
3. Версию iOS дочери записать в этот файл (строка в таблице выше), когда посмотрите — пригодится, если Expo когда‑нибудь попросит обновить систему.

**Версию iOS на iPhone 13 не знать сейчас — не блокер.** Для старта достаточно Expo Go; версию проверите перед первым совместным уроком с дочерью.

## 1. Что установить на Windows (один раз)

### Node.js (обязательно)

1. Скачать **LTS** с [https://nodejs.org/](https://nodejs.org/) (кнопка «LTS»).
2. Установить с настройками по умолчанию (в т.ч. «Add to PATH»).
3. Проверить в **PowerShell** или **cmd**:

```powershell
node -v
npm -v
```

Должны показаться версии, например `v22.x` и `10.x`.

### Git (желательно)

- [https://git-scm.com/download/win](https://git-scm.com/download/win) — чтобы клонировать репозиторий и делать коммиты.

### Редактор

- **Cursor** или **VS Code** — открывать папку проекта `MyApp6`.

### Expo Go на iPhone (у вас уже есть)

1. App Store → найти **Expo Go** → установить.
2. При первом запуске можно разрешить уведомления / сеть — для разработки достаточно локальной сети.

Тот же способ подойдёт для **Android**: приложение **Expo Go** из Google Play.

### Android-эмулятор (необязательно)

Нужен только если хотите эмулятор на ПК без телефона:

- Установить [Android Studio](https://developer.android.com/studio)
- В Android Studio: **Device Manager** → создать виртуальное устройство (AVD)
- При `npx expo start` нажать `a` — Expo попытается открыть эмулятор

Для семейного проекта обычно хватает **телефона + Expo Go**.

## 3. Как запускать проект каждый день

В той же папке:

```powershell
npx expo start
```

Появится меню в терминале и **QR-код** (в консоли или в открывшемся окне Metro / Dev Tools в браузере).

### Запуск на iPhone (Expo Go)

1. **iPhone и компьютер в одной Wi‑Fi сети** (домашний роутер; раздача с телефона тоже ок, если ПК подключён к ней).
2. На iPhone открыть **Expo Go**.
3. Отсканировать QR-код:
   - в Expo Go: **Scan QR code**, или  
   - камера iPhone → QR → открыть ссылку в Expo Go.
4. Подождать сборку (первый раз дольше). Откроется приложение «Распределяющая шляпа».

После правки `.js` файла и сохранения экран на телефоне **обновится сам** (fast refresh). Если нет — встряхнуть телефон → **Reload** или в терминале нажать `r`.

### Запуск в браузере на Windows

В терминале, где крутится `expo start`, нажать:

```text
w
```

Откроется веб-версия (удобно быстро проверить вёрстку; жесты меню могут отличаться от телефона).

### Запуск на Android-телефоне

Так же, как iPhone: **Expo Go** + QR, одна Wi‑Fi сеть.

### Клавиши в терминале Expo

| Клавиша | Действие |
|---------|----------|
| `w` | Открыть в браузере (web) |
| `a` | Android-эмулятор или устройство (если настроено) |
| `i` | iOS-симулятор — **только на Mac**, на Windows не сработает |
| `r` | Перезагрузить приложение на подключённых устройствах |
| `m` | Меню разработчика |
| `?` | Список всех команд |
| `Ctrl+C` | Остановить сервер разработки |

## 4. Если iPhone не подключается по QR

### Проверить сеть

- Один Wi‑Fi у ПК и iPhone.
- **Гостевая сеть** или изоляция клиентов на роутере иногда блокирует обмен — отключить «AP isolation» / подключить оба к основной сети.

### Режим Tunnel (обход проблем Wi‑Fi / firewall)

Остановить сервер (`Ctrl+C`) и запустить:

```powershell
npx expo start --tunnel
```

Первый раз может спросить установку `@expo/ngrok` — согласиться.  
QR будет работать медленнее, но часто помогает, когда ПК и телефон «не видят» друг друга.

### Брандмауэр Windows

При первом `expo start` разрешить **Node.js** доступ к частной сети (всплывающее окно Windows Defender).

### VPN

Отключить VPN на ПК и телефоне на время разработки.

## 5. Типичный рабочий процесс (папа + дочь)

1. Включить ПК, открыть проект в Cursor.
2. `npx expo start` в терминале.
3. Открыть приложение на iPhone через Expo Go (QR один раз за сессию).
4. Менять код (например `screens/HomeScreen.js` или `questions.js`) → сохранить → смотреть результат на телефоне.
5. Закончили — `Ctrl+C` в терминале.

## 6. Ошибки при старте

| Сообщение | Что сделать |
|-----------|-------------|
| `expo: command not found` | Использовать `npx expo start`, не просто `expo` |
| `ENOENT`, нет `node_modules` | Выполнить `npm install` в папке проекта |
| Порт занят | Закрыть старый терминал с Expo или `npx expo start --port 8082` |
| Версия SDK не совпадает | В Expo Go обновить приложение из App Store; в проекте `expo` в `package.json` должен соответствовать `sdkVersion` в `app.json` |

Логи с телефона: в Expo Go встряхнуть устройство → **Show Element Inspector** / консоль; на ПК смотреть красный текст в терминале Metro.
